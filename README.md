# Accessible Personal Portfolio

A responsive, multi-page portfolio starter using semantic HTML5 and accessibility-focused patterns.

## Pages
- `index.html` — Home
- `about.html` — About and skills
- `projects.html` — Project cards
- `contact.html` — Accessible contact form

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Customize before submitting
1. Replace every `Your Name` with your name.
2. Update the About page with your real education and skills.
3. Replace sample project descriptions with your own work.
4. Add your real contact details or connect the form to a backend/form service.
5. Test every page using keyboard navigation and Lighthouse.

## Accessibility features
- Semantic landmarks: `header`, `nav`, `main`, `section`, `article`, and `footer`
- Skip link and visible keyboard focus
- Descriptive page titles and meta descriptions
- Form labels, required fields, native email validation, and live status message
- Responsive layout and reduced-motion preference support

## Important
The contact form is a front-end demonstration only. It does not send or store messages. A Lighthouse score of 100 cannot be guaranteed on every device or audit run; verify the finished, customized site in your own browser.
